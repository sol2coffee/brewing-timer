# BREWING TIMER

모바일 브라우저에서 핸드드립 커피 추출 차수를 안내하는 브루잉 타이머 웹 앱입니다. 각 푸어링 차수의 시작 시각과 넣을 물양을 설정하면 누적 물양을 자동 계산하고, 타이머 실행 중에는 차수별 안내 문구와 배경색, 알림음, 진동을 제공합니다.

## 파일 구조

```text
brewing-timer/
├─ Index.html
├─ Code.gs
├─ appsscript.json
└─ README.md
```

## VS Code Live Server 실행

1. VS Code에서 `brewing-timer` 폴더를 엽니다.
2. Live Server 확장 프로그램을 설치합니다.
3. `Index.html`을 우클릭하고 `Open with Live Server`를 선택합니다.
4. 모바일 기기에서 테스트하려면 같은 네트워크의 스마트폰으로 Live Server 주소에 접속합니다.

별도의 Node.js, npm, 빌드 과정, 외부 CDN은 필요하지 않습니다.

## Google Apps Script에 파일 넣기

1. Google Apps Script에서 새 프로젝트를 만듭니다.
2. 기본 `Code.gs` 내용을 이 프로젝트의 `Code.gs` 내용으로 교체합니다.
3. 왼쪽 파일 추가 메뉴에서 HTML 파일을 만들고 이름을 `Index`로 지정합니다.
4. 이 저장소의 `Index.html` 전체 내용을 Apps Script의 `Index.html`에 붙여 넣습니다.
5. 프로젝트 설정에서 `appsscript.json` 표시를 켠 뒤, 이 저장소의 `appsscript.json` 내용으로 교체합니다.

## Apps Script 웹 앱 배포

1. Apps Script 상단의 `배포`를 선택합니다.
2. `새 배포`를 누릅니다.
3. 유형은 `웹 앱`을 선택합니다.
4. 실행 사용자는 본인으로 설정합니다.
5. 액세스 권한은 사용 목적에 맞게 선택합니다.
6. 배포 후 표시되는 웹 앱 URL로 접속합니다.

이 앱은 서버 데이터베이스를 사용하지 않으며, 레시피 설정은 접속한 브라우저의 `localStorage`에 저장됩니다.

## 주요 설정 항목

- 전체 추출 종료시간
- 저장된 레시피
- 언어 선택: 한국어, English, 中文, 日本語
- 1차부터 10차까지의 푸어링 차수
- 차수별 시작 시각
- 차수별 푸어링 물양
- 알림음 켜기/끄기
- 진동 켜기/끄기

기본 레시피는 HOT `60/80/80/80`입니다.

```text
1차: 00:00 / 60g
2차: 00:45 / 80g
3차: 01:30 / 80g
4차: 02:15 / 80g
추출 종료: 03:00
```

## 저장된 레시피

설정 화면 상단에서 `HOT` 또는 `ICE`를 먼저 고른 뒤 레시피를 선택하고 `레시피 적용`을 누르면 차수, 시작 시각, 물양, 추출 종료시간이 한 번에 채워집니다.

현재 기본 제공 저장 레시피는 비워둔 상태입니다. 사용자가 저장한 레시피가 HOT 또는 ICE 목록에 표시됩니다.

ICE 레시피를 저장할 때는 사전 준비 사항에 서버에 먼저 넣을 얼음량 안내를 함께 적을 수 있습니다.

현재 입력한 레시피는 `레시피 분류`에서 HOT/ICE를 고르고, `레시피명`을 입력한 뒤 `현재 설정 저장`으로 저장할 수 있습니다. `사전 준비 사항`에 서버 얼음량 같은 메모를 적으면 레시피와 함께 저장됩니다. 저장된 레시피는 선택한 소분류 안에 `나만의 · 이름` 형태로 표시되며, 선택 후 삭제할 수 있습니다.

저장한 레시피는 브라우저 `localStorage`에 저장됩니다. Apps Script 웹 앱으로 배포해도 각 사용자와 각 브라우저별로 따로 저장되므로 간단한 개인화는 가능합니다. 다만 다른 기기와 자동 동기화되지는 않습니다.

언어 선택값도 브라우저에 저장되며, 다음에 앱을 열 때 마지막으로 선택한 언어가 복원됩니다.

## 테스트 모드

URL 끝에 `?debug=1`을 붙이면 테스트 배속 선택이 표시됩니다.

```text
Index.html?debug=1
```

Apps Script 웹 앱 URL에서도 같은 방식으로 사용할 수 있습니다. 배속은 1배, 5배, 10배를 지원합니다.

## 브라우저 지원 범위

최신 Chrome, Safari, Edge, Firefox 기반 모바일 및 데스크톱 브라우저를 기준으로 작성했습니다.

- 타이머: `performance.now()`와 `requestAnimationFrame()` 지원 브라우저
- 화면 꺼짐 방지: Screen Wake Lock API 지원 브라우저에서만 활성화
- 알림음: Web Audio API 지원 브라우저
- 진동: Vibration API 지원 모바일 브라우저
- 설정 저장: `localStorage` 사용 가능 브라우저

지원하지 않는 기능이 있어도 앱의 핵심 타이머 동작은 계속 작동하도록 처리했습니다.

## 모바일 백그라운드 제한 안내

모바일 브라우저는 앱이 백그라운드로 이동하거나 화면이 꺼졌을 때 JavaScript 실행을 제한할 수 있습니다. 이 앱은 다시 활성화되면 실제 경과시간 기준으로 타이머 표시를 보정하지만, 백그라운드 상태에서는 알림음이나 진동이 제때 실행되지 않을 수 있습니다.

추출 중에는 가능하면 화면을 켜둔 상태로 사용하세요. 지원 브라우저에서는 START 시 Screen Wake Lock API로 화면 꺼짐 방지를 요청합니다.

## 입력 검증

START 전에 다음 조건을 확인합니다.

- 차수는 1개 이상 10개 이하
- 각 차수 시작 시각은 이전 차수보다 늦어야 함
- 각 차수의 푸어링 물양은 0보다 큰 숫자
- 전체 추출 종료시간은 마지막 차수 시작 시각보다 뒤
- 전체 추출 종료시간은 최소 5초 이상
- 빈 값, 음수, NaN, Infinity는 허용하지 않음

오류가 있으면 해당 입력 필드를 강조하고 한국어 오류 메시지를 표시합니다.
